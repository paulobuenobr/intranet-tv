Como usar a API?

Logo a seguir você encontrará todos os recursos e metódos suportados pela API, sendo que essa página possibilita que você teste os recursos e métodos diretamente através dela.

Autenticação

Para qualquer requisição de nossa API, você precisa informar, através do método POST, os dados de autenticação, que são:

  • keyapi: string (contendo a chave de acesso pra validar o acesso).
  • login: string (login do usuário)
  • pass: string (senha do usuário),

Caso os dados de autenticação contenha algum erro, receberá como retorno, o seguinte JSON:

{    
  "retorno_status":false,
  "error":"Dados de autenticação são inválidos!"
}

Em todas as requisições, no caso de algum erro, sempre retorna o parâmetro "retorno_status" como "false", e "error" com a descrição do erro. Em caso de sucesso, retorna "retorno_status" = "true" com os demais dados de cada tipo de requisição.
